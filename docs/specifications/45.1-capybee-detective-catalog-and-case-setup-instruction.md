# Spec 45.1 — CapyBee Detective Catalog and Case Setup

**Depends on** [27.27.4](27.27.4-engine-dynamic-web-session-api-and-jdbc-persistence-instruction.md) and [28.2](28.2-game-preparation-and-start-instruction.md).

## Catalog and eligibility

- Package the canonical `classic-detective` profile in the server alongside `generic-adventure`. Include both in Fly's default dynamic profile allowlist and honor the existing deployment override and generation switch.
- In Play → Adventures, display the detective profile's English or Polish title and case description in the shared adventure row. Use the existing dynamic capability and server discovery results. The active family profile's entire birth-year age interval must fall within ages 15–17 for detective discovery and start.
- Keep the existing authored adventure cards and generic AI adventure available under their current eligibility rules.

## Preparation and confirmation

- Reuse Quick Start, Customize, Review, and the shared adventure renderer. Quick Start chooses valid presets and proceeds to Review. Customize uses the profile's mystery type, setting, tone, investigation elements, medium length, difficulty, story language, and optional fictional idea.
- Show the AI disclosure at review. Describe the external service transfer and saved case without promising an authored detective fallback.
- Start AI generation through the existing dynamic start endpoint after explicit confirmation, with the selected locale, presets, profile identity and fingerprint, and disclosure revision. Preserve the existing replacement confirmation, polling, and saved-run handling.

## Acceptance

- Verify the packaged detective profile loads and returns localized settings for an eligible player. Verify younger profiles retain access to their existing options and the detective profile cannot be selected by bypassing the catalog.
- Verify Quick Start and Customize can reach Review without a start request and confirmation sends the detective profile and selected settings through the dynamic start flow.
