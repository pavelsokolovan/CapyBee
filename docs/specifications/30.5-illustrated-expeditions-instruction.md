# Spec 30.5 — Illustrated expeditions

**Intent:** [Illustrated Honeycomb RPG](intent/03-illustrated-honeycomb-rpg.md)
**Depends on:** 30.1–30.4
**Baseline:** `5ccf735`
**Status:** Implemented 2026-11-16; see [acceptance](../game-illustrated-expeditions-acceptance.md)

Compose the accepted current moment as a calm illustrated encounter: a fixed
catalog backdrop, discovered current characters with public names/traits/needs,
shared dialogue, and existing choices together. Keep text on an opaque readable
surface below the image. Reuse the current character cards; do not add a second
cast or duplicate dialogue/actions. The board and party remain separate surfaces.

Use only normalized public presentation IDs and existing SVG renderers. Artwork
is decorative beside equivalent readable text. Unknown IDs use catalog fallback;
missing presentation retains the shared text-first renderer. No scene IDs,
flags, private cast, generated images, network artwork or Pack/version branches.

Provide an EN/PL native “Text mode” toggle for the active run. It removes
encounter art and companion portraits and forces the board's equivalent list.
Keep names, traits, needs, dialogue, choices, hints, current location and party.
Do not remount the response form, erase a draft, submit a command or change focus
when switching. Keep the preference only in memory and reset on run replacement.
Forced colors also suppress decorative imagery; reduced motion adds no animation.

Retain the controller's accepted-state rendering and focus rules. Pending,
rejected and offline choices keep the accepted backdrop and characters; entering
an encounter does not recruit a character. Endings retain existing result and
completion controls. All choices still use the shared SceneActions exactly once.
No engine/server changes, new Pack, generation/prefetch or rewards in this part.

Use responsive width, wrapping ordinary HTML and at least 44px controls. At
360px and 200% zoom no horizontal page overflow or clipped choices. Accessible
text remains usable with SVGs hidden. Keep shell labels localized and story
content in its existing language.

Verify component composition, optional/unknown art, pending accepted-state reuse,
EN/PL controls, draft/focus preservation and no mutations on mode switch. Extend
real Spring/PostgreSQL browser acceptance for illustrated encounters and text/list
parity, reload's quiet default, mobile/zoom/forced colors and unchanged choices.
Run frontend coverage and official build/static sync, compare both static copies,
and run the integrated browser gate. Record screenshots and checks in
`docs/game-illustrated-expeditions-acceptance.md`. Commit on main after passing.
