# Spec 45.3 — CapyBee Detective Character Art and Investigation Screens

**Depends on** [45.1](45.1-capybee-detective-catalog-and-case-setup-instruction.md), [45.2](45.2-capybee-detective-ai-case-generation-and-validation-instruction.md), and the shared adventure presentation and scene renderer.

## Cast and artwork

- Feature CapyBee as the detective’s companion in new English and Polish cases. The generated case supplies an original lead investigator, client and suspects. Introduce the investigator and CapyBee in the opening scene.
- Use the local CapyBee figure, a detective portrait, reusable cast portraits and an illustrated study backdrop. Treat the study as a decorative frame for the case. The accepted scene text describes the actual setting.
- Assign portraits from the built-in catalog using stable cast roles and ordering. Project artwork only for characters discovered in the current or previously visited scenes. Preserve the generated names and descriptions. Older detective runs can use the same layout with the cast already in their saves.

## Investigation screen

- Use the existing Adventures entry, scene text, choice buttons, character panels, and run controls. Label the detective objective panel **Case notes** in English and **Notatki ze śledztwa** in Polish.
- Show the exact accepted observation when a clue objective is complete. Keep the investigation task text visible for objectives the player has yet to complete. Reconstruct notes from the accepted run when it resumes.
- Offer text mode on the detective screen. Hide decorative artwork in text mode and forced colors and keep the full scene, case notes, cast text, and legal actions accessible. Support keyboard operation and narrow mobile screens.

## Acceptance

- Verify discovery-only portraits and case notes before and after a clue, including after provider-free resume.
- Verify both languages, equal action availability across reading modes, and the detective layout in a mobile-width browser.
