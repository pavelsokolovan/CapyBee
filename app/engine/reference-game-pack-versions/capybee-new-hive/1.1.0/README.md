# CapyBee — Nowy ul, dwa światła (1.1.0)

Optional Polish presentation generation over the unchanged 1.0.0 authored
mechanics and routes. `generation/catalog.json` declares THEME → SCENARIO →
QUEST → CAST and scene generation on entry, with reviewed indexed Polish
fallbacks for every slot. `AUTHORED_GRAPH` preserves optional encounters,
revisits and three equally valid resolutions including rest.

Tone and interests are enumerated; mood is optional and initially unset. The
fictional wish is optional, limited to 240 Unicode code points and must cross
the host transient, guarded preparation boundary. It is not a durable start
input. The CLI can use the complete offline fallback without a provider.

The previous version stays in `reference-game-packs/capybee-new-hive` and in
host/distribution `retained/1.0.0`. See the original content inventory for the
unchanged scene/place/actor identities and authored route scripts. Mission
binding proposals remain host-owned and are activated separately by 29.4.

See `docs/polish-theme-generation.md` for consent, retention audit, operator
approval, exact request contract and verification. Live generation defaults off;
implementation and deterministic tests do not approve child-audience provider
use.
